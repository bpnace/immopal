# Contributing

ImmoPal is primarily a portfolio project. Small issues, accessibility notes, and maintainability suggestions are welcome when they improve the public code sample.

## Local Checks

```bash
npm ci
npm test
npm run build
```

## Pull Requests

- Keep changes focused and easy to review.
- Do not add secrets, real customer data, or private deployment details.
- Include a short note describing what changed and how it was verified.
