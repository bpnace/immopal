# Security Policy

## Scope

This repository is maintained as a public portfolio project. Security reports should focus on source-code risks, exposed secrets, dependency vulnerabilities, and CI configuration.

## Reporting

Please do not open public issues for exploitable vulnerabilities. Send a private report through GitHub Security Advisories or contact the repository owner directly.

## Baseline

- No credentials, `.env` files, or PEM keys should be committed.
- Dependabot alerts and GitHub code scanning are monitored for the default branch.
- Public examples use placeholder URLs or non-sensitive configuration.
